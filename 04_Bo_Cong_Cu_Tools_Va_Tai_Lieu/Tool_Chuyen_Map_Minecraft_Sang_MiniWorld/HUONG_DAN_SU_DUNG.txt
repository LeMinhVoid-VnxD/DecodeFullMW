    CONG CU CHUYEN DOI BAN DO MINECRAFT (.MCA) SANG MINI WORLD (.R)
================================================================================

Thu muc cong cu: C:\Users\Le Minh\OneDrive\Desktop\decodepkg\mc2mw_converter

Cac file trong bo cong cu:
  1. MC_to_MiniWorld_Converter.exe -> File chay truc tiep khong can cai Python.
  2. mc2mw_gui.py                 -> Giao dien do hoa nguoi dung (Tkinter GUI).
  3. KEO_THA_MAP_MC_VAO_DAY.bat   -> File khoi chay nhanh 1-Click hoac keo tha file/folder map Minecraft.
  4. converter_core.py            -> Engine xu ly chuyen doi block va cau truc du lieu.
  5. block_mapping.py             -> Bang tu dien anh xa block Minecraft -> Mini World.
  6. mc_mca_reader.py             -> Module doc file Region .mca (Minecraft 1.12 den 1.20+).
  7. mw_region_writer.py          -> Module tao file Region .r va thu muc save game Mini World.
  8. HUONG_DAN_SU_DUNG.txt        -> Huong dan su dung chi tiet.

--------------------------------------------------------------------------------
CAC TINH NANG NOI BAT:
--------------------------------------------------------------------------------
1. HO TRO TOAN DIEN PHIEN BAN MINECRAFT:
   - Tu dong nhan dien va doc moi phien ban Minecraft Java & Bedrock (1.12, 1.13, 1.16, 1.18, 1.20+).
   - Xu ly ca mảng byte cu (Blocks/Data) va Palette bitstream packed hien dai.

2. ANH XA BLOCK CHINH XAC (BLOCK MAPPING):
   - Chuyen doi day du tu Dia hinh (Dat, Co, Da, Cat, Soi, Da Nen),
     Go & Cay coi (Cac loai go, van go, la cay),
     Quang khoang san (Than, Sat, Vang, Kim Cuong, Lapis, Redstone, Emerald),
     Chat long (Nuoc, Dung Nham),
     Kien truc (Gach, Thuy tinh, Len mau, Betong, v.v.).

3. TU DONG TICH HOP VAO GAME MINI WORLD:
   - Tu dong tao thu muc ban do chuan: data/w{WorldID}/m0/*.r
   - Tu dong tao file map.ini chua thong tin ten map, che do choi (Sang tao), seed.
   - Ho tro xuat thang vao thu muc game cua Mini World (%APPDATA%\miniworddata410\data\)
     de khi mo game Mini World len la thay map va vao choi duoc ngay!

--------------------------------------------------------------------------------
HUONG DAN SU DUNG:
--------------------------------------------------------------------------------

CACH 1: Su dung Giao dien Do hoa (GUI - Khuyen dung)
  1. Nhap dup (double-click) vao file "MC_to_MiniWorld_Converter.exe" hoac "KEO_THA_MAP_MC_VAO_DAY.bat".
  2. Cua so chuong trinh se hien len:
     - Muc 1: Bam "Duyet..." de chon Thu muc Map Minecraft can chuyen (hoac chon file .mca don le).
     - Muc 2: Chon xuat truc tiep vao game Mini World (hoac chon thu muc bat ky tren Desktop).
     - Dat ten cho ban do Mini World.
  3. Bam nut "BAT DAU CHUYEN DOI NGAY".
  4. Sau vai giay, ban do da san sang de vao Mini World trai nghiem!

CACH 2: Keo tha (Drag & Drop)
  - Keo thu muc map Minecraft (hoac file .mca bat ky) roi tha de len file "KEO_THA_MAP_MC_VAO_DAY.bat"
    hoac "MC_to_MiniWorld_Converter.exe".
